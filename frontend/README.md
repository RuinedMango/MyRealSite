# frontend

Vite + Tailwind + TypeScript assets for the Javalin app.

```bash
bun install
bun run dev    # Vite dev server on http://localhost:5173
bun run build  # production build into ../build/generated-resources/public/assets
bun run check  # TypeScript type-check
```

From the repository root, `./scripts/dev.sh` starts Vite and the app together.
